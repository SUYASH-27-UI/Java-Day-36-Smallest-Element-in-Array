# Java Day 36 - Smallest Element in an Array

## Description
This Java program finds the smallest element in an integer array using a for loop.

## Example
**Array:** `{25, 80, 45, 20, 60, 90}`

**Output:** `Smallest element = 20`

## Concepts Used
- Arrays
- For Loop
- If Statement
- Comparison Operator

## How to Run
1. Save the code as `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.
